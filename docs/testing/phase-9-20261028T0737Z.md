## 4. Defects

### P9-D1 (Medium, Phase 9 gate): RAGAS contexts omit the live web evidence the answer used

**What happens:**
- `scripts/ragas_eval.py` `contexts_of()` reads only `retrieval` events.
- Tavily results arrive in a separate `web_search` event (`results[]` with `cite_id`, `title`, `snippet`). No `retrieval` event of type `web` exists.
- So the "web results by their snippet" branch never runs, and W#-backed claims are judged against paper chunks only.

**Affected items:**
- routed-deployed c06 (W1–W3 cited; all 4 metrics).
- forced-gemini-local c06 (W1, W2) and p02 (W1–W4) (faithfulness).

**Reproduce:**
```
.venv/bin/python -c "import json;E=[json.loads(l) for l in open('eval/results/phase9/routed-deployed/c06.run1.events.jsonl')];print({c['type'] for e in E if e['event']=='retrieval' for c in e['data']['chunks']}, [e['event'] for e in E if e['event']=='web_search'])"
```
This prints `{'paper_chunk'} ['web_search']`, while the answer contains `[C13, W1]` and `[W1, W3]`.

**Expected:** The contexts are what the workers actually received (evaluation.md §1 and the scorer docstring).

**Actual:** Web evidence is missing from the contexts. That is enough to change the score: c06 is 0.875 with web contexts against 0.808 recorded.

**Impact:**
- Main faithfulness mean: at most +0.006 (bound 0.987).
- Forced-Gemini faithfulness: at most +0.014 (0.966 → ≤ 0.980). The reported OpenAI/Gemini gap (0.994 vs 0.966) could halve.
- evaluation.md names c06 as the faithfulness minimum and p02 as Gemini's lowest item. Both are partly this artifact.

**Related:** `docs/design_proposal.md:468` planned RAGAS runs "with live search disabled". The runs were end to end with live search on, and evaluation.md does not say so.

**Fix:**
1. Include `web_search` results (`title: snippet`) in `contexts_of`, in first-seen order.
2. Add a unit test with a fixture containing a `web_search` event.
3. Rescore routed c06 (4 metrics) and forced-Gemini c06 and p02 (faithfulness, answer relevance). Answer relevance does not use contexts, but this keeps the rows consistent.
4. Rerun `summarize_phase9.py`.
5. Update evaluation.md §1, §3 and §7, and state that live search was on during the RAGAS runs (or reconcile the design proposal).

**Rubric:** RAG 20 % (honesty and correctness of the RAGAS figures) and the routing comparison.

## 5. Notes (non-blocking)

**P9-N1 (Low, product, citation linking): markers after a sentence's final period are attributed to the next clause.**
- **Where:** `abstention_only_markers` splits on `(?<=[.!?])\s+`. So in "...layout. [C8][C9][C10] The available evidence does not answer...", the markers join the abstention clause.
- **Effect:** In forced-openai p02, `[C10]` supported the "Bottom line" claim but was dropped (`done.dropped_citations=['C10']`). It shows as an unlinked marker.
- **Reproduce offline:** `abstention_only_markers('Reliability depends on the layout. [C8][C10] The available evidence does not answer whether newer models do.')` returns `{'C8','C10'}`. With the markers before the period it returns `set()`.
- **Scope:** 1 of 119 runs (s18's dropped C1 is a genuine abstention).

**P9-N2 (trivial, documentation): small number differences.**

  - Context recall is 0.914 in the doc but 0.9135 exact, which rounds to 0.913.
